Challenge 2 [60 marks]
You are required to develop a computer game. You need a class named TankGame to implement the program.
There are 3 small tanks and one MainTank. The objective of the game is to collect balls from each small tank into
the MainTank. The descriptions of the game are as follows:
1. The game should start with random number of balls (minimum 0 and maximum 5) in each small tank.
2. Each ball can only travel from one small tank to another in order to reach the mainTank.
3. The game will terminate once all the balls from each tank moved into the MainTank.
Implement the game. You are required to at least include the following:
1) To use void and value methods to implement the strategies in the game.
2) To implement the main method
